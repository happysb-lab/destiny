# 핀볼 추첨

구슬을 굴려 당첨자를 뽑는 핀볼 추첨기. 단일 `index.html`, 의존성 없음.

- 참가자: 쉼표·줄바꿈 구분, `이름*3` 은 구슬 3개
- 당첨 기준: 1등 / 꼴등 / N등
- 골인 직전 슬로모션·줌인, 순위 패널, 미니맵

## 실행

```
python3 -m http.server 8000
```

`http://localhost:8000` 접속. 파일을 직접 열어도 동작한다.

## 관리자

화면 **우측 상단 모서리를 1.5초 안에 7번** 누르면 관리자 창이 열린다.
당첨자를 지정하면 선택한 당첨 등수(1등/꼴등/N등)에 그 사람이 반드시 들어간다.
설정은 브라우저(localStorage)에 저장되며 "랜덤"을 고르면 해제된다.
